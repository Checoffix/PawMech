# PawMech

Аркадный 2D Bullet-hell экшен про боевого кота на мехе, созданный в рамках **Mini Jam 202: Action**.

🏆 **Результаты джема:**
- **#24 Presentation / Visuals** 

🎮 **Поиграть на itch.io:** https://checoffix.itch.io/pawmech

### Что реализовано по кодовой части (68 скриптов C#):
- **Полиморфная система способностей:** базовый класс `BaseSkill` и модульные типы скиллов (бомбы, лазеры, дробовик, иллюзии, баффы). Логика ввода комбо-последовательностей (`PlayerMakingSequence`, `SkillSequenceHUD`).
- **Механика перегрева и QTE:** отслеживание температуры орудий мехи (`OverheatHUD`), динамические QTE-сегменты с таймингами для быстрого охлаждения (`OverheatQTESegments`, `QTEMovement`).
- **Траектории движения врагов (паттерн Strategy):** модульные паттерны движения (`MovementPattern`, `ArcPattern`, `LinearPattern`), позволяющие независимо настраивать траектории полета разным типам врагов.
- **Иерархия мобов и снаряды:** классы врагов (`BurstEnemy`, `CircleEnemy`, `LaserEnemy`, `ClusterEnemy`), кассетные и линейные снаряды.
- **Система волн:** спавнер врагов по волнам (`WaveSystem`, `WaveController`), подсчет очков и условия победы/поражения.

**Стек:** Unity, C#, 2D, модульная архитектура способностей, паттерны проектирования (Strategy, FSM).
